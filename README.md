# MVP-инструмент для синтетической генерации и анонимизации данных

Веб-приложение (Single Page Application) для быстрого создания реалистичных тестовых датасетов и обезличивания конфиденциальных CSV-таблиц. Инструмент разработан в рамках ознакомительной практики и призван автоматизировать развертывание безопасных тестовых сред (QA/DevOps), исключая риски утечки персональных данных.

---

## 🛠 Технологический стек

* **Backend:** Python 3.11+, FastAPI (асинхронный веб-фреймворк), Uvicorn (ASGI-сервер).
* **Валидация и парсинг:** Pydantic v2 (строгая валидация конфигураций), Pandas + встроенный сниффер (автоматическое определение разделителей в CSV: `,`, `;`, `\t`).
* **Генерация данных:** Библиотека `Faker` (локализация `ru_RU`).
* **Frontend:** Vanilla JS (модульная структура), HTML5, CSS3 (анимации, тема Glassmorphism).
* **Хранение настроек:** `localStorage` браузера (`anonymiz_settings`) для сохранения пользовательских кастомизаций темы.
* **Криптография:** Встроенная библиотека `hashlib` (алгоритмы MD5, SHA-256).
* **Контейнеризация:** Docker, Docker Compose.

## 🚀 Как запустить

### Вариант 1. Запуск через Docker (Рекомендуемый)

Убедитесь, что у вас установлены Docker и Docker Compose.

1. Клонируйте репозиторий и перейдите в корневую директорию проекта:

```bash
git clone https://github.com/your-username/data-anonymizer-generator.git
cd data-anonymizer-generator
```

2. Разверните и запустите контейнеры:

```bash
docker-compose up --build
```

3. Приложение будет доступно в браузере по адресу:

```text
http://localhost:8000
```

---

### Вариант 2. Локальный запуск (Разработка)

Для запуска требуется установленный Python версии **3.11+**.

1. Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv

# Для Windows
venv\Scripts\activate

# Для macOS/Linux
source venv/bin/activate
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите сервер Uvicorn:

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

4. Откройте страницу:

```text
http://127.0.0.1:8000
```

Интерактивная документация API (Swagger) доступна по адресу:

```text
http://127.0.0.1:8000/docs
```

## Сценарий 1. Синтетическая генерация данных

### Шаг 1. Выбор шаблона

Выберите базовую схему данных:

### Шаг 3. Экспорт

* Ознакомьтесь с таблицей предпросмотра (первые 5 строк).
* Нажмите кнопку **«Скачать»**.

## Сценарий 2. Анонимизация конфиденциальных файлов

### Шаг 1. Загрузка

Перетащите файл (**Drag & Drop**) или выберите вручную исходный файл формата `.csv`.

### Шаг 2. Настройка правил

Автоматический сниффер определит разделитель таблицы.

Для каждой колонки выберите метод обработки:

| Метод         | Описание                                            |
| ------------- | --------------------------------------------------- |
| Маскирование  | Скрытие части строки символами `*`                  |
| Хеширование   | Преобразование значения в MD5/SHA-1/SHA-256/SHA-512 |
| Удаление      | Полная очистка содержимого ячеек                    |
| Без изменений | Сохранение исходного значения                       |

#### Маскирование

Указываются:

* индекс начала маскирования;
* количество скрываемых символов.

Пример:

```text
+79502221133
↓
+79*****1133
```

### Шаг 3. Верификация

* Проверьте результат в таблице предпросмотра.
* Скачайте обезличенный файл.

---

### Пример работы алгоритмов

#### Входной файл (`исходный_orders.csv`)

```csv
order_id;client_fio;phone;date;status
1024;Петров Петр Петрович;+79502221133;2026-05-12;Доставлено
1025;Иванов Иван Иванович;+79001112233;2026-05-13;В обработке
```

#### Выходной файл (`anonymized_orders.csv`)

**Настройки обработки:**

* `order_id` — без изменений;
* `client_fio` — хеширование MD5;
* `phone` — маскирование с 3-го символа длиной 5 символов;
* `date` — удаление;
* `status` — без изменений.

```csv
order_id;client_fio;phone;date;status
1024;e9ba56214591a27e387c95a53109a252;+79*****1133;;Доставлено
1025;adc149615a1372cf93c0422c1598f804;+79*****2233;;В обработке
```

## 🧪 Интеграционное тестирование

Система покрыта комплексными тестами.

### ✅ Валидация API (Pydantic)

Проверяются следующие сценарии:

* блокировка генерации более **10 000 строк**;
* обработка пустых файлов;
* обработка поврежденных CSV-файлов;
* проверка корректности конфигураций пользователя.

### ✅ Тестирование парсера

Проверена корректность чтения таблиц с разделителями:

* `,`
* `;`
* `\t`

Пример тестового набора:

```text
name,email
```

```text
name;email
```

```text
name\temail
```

### ✅ Валидация масок

Алгоритмы протестированы с использованием регулярных выражений для обработки различных форматов:

* телефонных номеров;
* адресов электронной почты;
* строк произвольной длины.

Пример:

```text
ivanov@mail.ru
↓
iva*****mail.ru
```
